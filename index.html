About SkyCast

SkyCast is a modern and interactive weather web application designed to deliver real-time weather insights with a clean and visually engaging experience.

Key Features

  • Real-time temperature, humidity, and wind updates
  • Dynamic background based on time (morning, afternoon, evening, night)
  • Automatic dark mode for better night readability
  • Animated weather effects like rain
  • Smart city search with accurate results

User Experience

The app is designed with a focus on simplicity and clarity. Glassmorphism UI, smooth transitions, and responsive layout ensure a seamless experience across devices.

Future Improvements

  • Auto location detection
  • Lightning & storm animations
  • Progressive Web App (PWA) support

Built with passion to make weather information simple, beautiful, and interactive.

How to Use SkyCast

Get accurate weather insights in just a few simple steps

Search Your City

Type your city name in the search bar and hit the search button to get instant results.

Check Weather Data

View real-time temperature, humidity, wind speed, and direction in a clean layout.

Experience Live Effects

Dynamic rain animation appears automatically when rainy conditions are detected.

Smart Theme Switching

The interface automatically adapts between day and night modes based on time.

Tip: Enter correct city names (e.g., Delhi, Mumbai) for accurate results.

Use your location?

We can show weather for your current location instantly.
